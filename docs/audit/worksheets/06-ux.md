# UX heuristic review — findings

Reviewed at 1440px+ and 390px, logged in as owner. Overall the visual design is
strong and coherent: consistent dark theme + orange accent, good typographic
hierarchy, clean status pills, a genuinely nice mobile bottom-nav, and clear
step wizards. The gaps below are specific, not a wholesale redesign.

### UX-1 — Dashboard and Billing report spend against different limits with different framing
- **Severity:** P1
- **Dimension:** ux
- **Location:** screen /dashboard ("MONTHLY SPEND $54.00 / $250.00 · 22%") vs /billing ("$54.00 used of $25.00 included this month")
- **What's wrong:** The same $54 spend is shown as 22% of a $250 cap on the dashboard but as over the $25 included allowance on billing. Two screens, two limits, two contradictory impressions of the same fact.
- **How it fails:** A user glances at the dashboard, sees plenty of headroom (22%), then hits "Billing inactive" and an over-allowance message on billing — with no explanation of why the numbers differ. Erodes trust in the billing data.
- **Proposed fix:** Show both concepts explicitly and consistently on both screens: "included allowance" (resets per billing period) vs "hard spend cap," with the same window. Ties to BILL-11/DATA-15.
- **Effort:** M

### UX-2 — Avatars are all labeled "Default avatar" with no name, thumbnail, or metadata in the list
- **Severity:** P2
- **Dimension:** ux
- **Location:** screen /avatars
- **What's wrong:** Five avatars all render as "Default avatar / Ready" — indistinguishable. The list rows have no thumbnail, name field, or creation date; only the separate "looks" grid shows images.
- **How it fails:** A user with multiple avatars cannot tell which is which to pick "Set active" or "Delete" — a coin-flip that can activate/delete the wrong one (compounded by DATA-12, where a failed delete silently reports success).
- **Proposed fix:** Let users name avatars on creation; show a thumbnail + name + created date per row; default the name to something meaningful.
- **Effort:** M

### UX-3 — Settings profile form has no field validation
- **Severity:** P2
- **Dimension:** ux
- **Location:** screen /settings (candidate profile)
- **What's wrong:** Fields accept arbitrary free text with no validation or constraint (observed live data: Party = "congress", District = free text, Running for = "state assembly LA"). Garbage in these fields flows into AI generation prompts (src/lib/prompt.ts) and disclosures.
- **How it fails:** A typo or nonsense value silently degrades every AI draft and video script grounded on the profile; no inline feedback tells the user anything is wrong.
- **Proposed fix:** Add inline validation/constraints (required fields, party as a select or validated string, sane max lengths) and surface errors inline on save.
- **Effort:** M

### UX-4 — Monitoring excerpts truncate mid-word with no ellipsis
- **Severity:** P3
- **Dimension:** ux
- **Location:** screen /monitoring (item excerpts)
- **What's wrong:** Excerpts cut off mid-word ("…and the transfe", "…legitimate, th") with no ellipsis or "read more" affordance.
- **How it fails:** Looks broken/unfinished on an otherwise polished screen; the user can't tell where the excerpt ends.
- **Proposed fix:** Truncate on a word boundary with an ellipsis (CSS line-clamp), or add a "read more" toggle.
- **Effort:** S

### UX-5 — Monitoring feed surfaces clearly off-topic items (relevance quality)
- **Severity:** P3
- **Dimension:** ux
- **Location:** screen /monitoring
- **What's wrong:** For a California Assembly District 12 race, the feed shows unrelated foreign news (Islamabad High Court / PTI / Imran Khan items). Credibility is a flat "Medium" on every item.
- **How it fails:** The core value prop ("monitor your opponents") is undercut when the feed is full of irrelevant results; users lose trust in the intelligence. (Partly seed/test-data noise, but also reflects weak relevance filtering + flat credibility scoring — see credibility.ts and the n8n query in INT-12.)
- **Proposed fix:** Tighten the monitoring query to the campaign's actual entities/geography; make credibility scoring meaningfully vary; add per-item relevance and a way to tune keywords.
- **Effort:** M

## Positives (worth preserving)
- Cohesive, professional dark visual system; strong hierarchy and spacing.
- Mobile: sidebar collapses to an icon bottom-nav; content stacks; no horizontal table overflow at 390px.
- Status pills are consistent and color-meaningful across dashboard and content list.
- Content wizard's numbered step indicator is clear.
- No console errors observed on the pages visited.
